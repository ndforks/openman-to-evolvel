# Skills

A skill is a folder of guidance (a `SKILL.md` file, sometimes with scripts) that shows the agent how to handle one kind of job. The agent pulls a skill in when a task needs it.

## Sources of skills

- **Built in.** Hermes Agent comes with skills that are present on every computer. They are read from the computer itself, and you can switch them off but not remove them.
- **Official library.** 55 skills that install with one click: 46 from Nous Research (who make Hermes Agent) and 9 from Anthropic, sorted into Coding, Data, Automation, Business, Design, Media, Content and Apps. Each one lists its publisher, licence and source.
- **Yours.** Skills you write or find elsewhere (see below).

The **Skills** page in the app is where you browse, install, enable, disable and remove them.

## Adding your own

- **Upload** a `.zip`, a `.skill` file, a `SKILL.md` file or a folder.
- **Import from GitHub** by pasting the URL of a public repository containing a skill.
- **Write it** in the app: a name, a description of when it applies, and the instructions.

## Making a skill from a task

After a task that went well, ask {{name}} to turn it into a skill. The agent packages its approach into a reusable skill for you to review and install.

## Downloading

Download any installed skill as a `.zip` to keep, change or pass on.

## Where skills live

Skills are installed on the computer the agent works on, so every task on that computer can use them.
