# Sharing and replay

Sharing a task lets someone else see what the agent did.

## Sharing a task

In the task, choose **Share**, pick **Anyone with the link** and copy it. Anyone holding the link can open the task without an account. Switch back to **Private** to stop: from then on only you can open the link.

**Settings → Data controls** gathers every task you have shared, so you can check them all in one list.

## What people with the link see

- The conversation, the plan and each tool step, read-only.
- Any files the task created.

They cannot see your computer's live screen, send messages or run anything. Text that resembles a password, key or token is masked in the shared view.

## Replay

Append `?replay=1` to a shared link to play the task back one step at a time at an easy pace, with Play and Pause buttons. Replay is built from the saved steps, not from a screen recording.
