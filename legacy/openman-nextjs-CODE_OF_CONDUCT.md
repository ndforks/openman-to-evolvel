# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
By taking part in this project (issues, pull requests, discussions and any other project space) you agree to follow it.

In short: be welcoming and respectful, assume good intent, give and accept constructive feedback, and do not harass,
insult or demean anyone.

## Reporting

Report unacceptable behaviour to the maintainers at **contact@orgo.ai** with "OpenMan code of conduct" in the subject.
Reports are reviewed promptly and kept confidential as far as possible. Maintainers will act according to the
enforcement guidelines of the Contributor Covenant 2.1 (correction, warning, temporary ban, permanent ban).

Security vulnerabilities are not conduct issues: report them as described in [SECURITY.md](SECURITY.md).
