# Projects

Projects group related tasks under one set of instructions, so you only explain things once.

## Creating a project

Choose **New project** in the sidebar, name it and open it. Any task started inside the project belongs to it. Rename, pin, reorder or delete projects from the sidebar; deleting a project leaves its tasks in place.

## Instructions

Write the instructions once, for instance *"Write in British English and cite every source"*, and every task in the project receives them.

## Connectors and skills

Pick the connectors a project should use and they come preselected in the input box for its tasks. Projects can also carry a set of skills. See [Connectors](/docs/connectors) and [Skills](/docs/skills).

## Files

Attach files to a project: up to 2 MB per file and 50 files per project. They are stored with the project, but the agent does not open them on its own yet; to use one, attach it to the task as well.
