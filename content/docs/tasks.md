# Tasks and the computer

A task is a single job you give the agent. It works through the job on a cloud computer, and you can watch, redirect it or take control along the way.

## Starting a task

Write the job in the home screen's input box and send it. Before sending you can also:

- **Add files** from your device with the **+** button, up to 4 MB each.
- **Pick the computer** with the chip above the input: your home computer (the default, which gives every task its own working folder) or another of your cloud computers. Each project remembers its choice.
- **Choose a mode** to set the model. See [Modes and models](/docs/modes-and-models).
- **Dictate**: the microphone button converts speech to text using your browser's speech recognition.

## Watching the work

The task view puts the conversation on the left and the agent's computer on the right. You see the plan, every tool call (browser, terminal, files) and each file the agent produces. Open files in place or download them; all task files are also collected in your **Library**.

Close the page and return later, and the view resumes where it was.

## Messaging a running task

You can write to the agent mid-run and decide how your message is delivered:

- **Slip in while it works**: the agent factors it into the run already under way.
- **Stop and send now**: the agent halts and reads your message before anything else.
- **Send when it finishes**: the message is held until the current run finishes.

**Stop** ends the run and discards anything still queued.

## When the agent needs you

The agent pauses when it has a question it cannot settle alone, or before an action that needs your permission. Reply inside the task and it picks up again.

Before the agent operates a desktop app on the computer, it asks once per app. Choose allow once, always allow or never allow; your standing choices are listed on the **Computer use** page and can be changed there.

## The computer panel

This panel shows the computer's screen live. It starts in view-only mode so a stray click does nothing.

- **Take the controls** hands you the mouse and keyboard, for signing in to a site, getting past a CAPTCHA or demonstrating something.
- **Give back control** puts the panel back into view-only mode.

The agent keeps working while you are in control, so let it know what you are doing (or stop it first) if you might get in each other's way.

The live view of a computer is visible to you alone. Anyone you share a task with gets a record of it, not the live screen (see [Sharing and replay](/docs/sharing)).
