# Chat channels

For now, you work with the agent in the {{name}} web app, from any device that has a browser.

{{name}} does not yet offer a Slack, Telegram, WhatsApp or iMessage channel, or a desktop or mobile app. New channels will be described on this page when they arrive.

## Other ways to get work started

- **Automations** launch tasks on a schedule, from a webhook or from an RSS feed. See [Automations](/docs/automations).
- **Connectors** let a task reach into your apps, for example to post a Slack message or send an email. See [Connectors](/docs/connectors).
